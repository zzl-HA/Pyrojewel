## 电机运动（单一）

### 功能描述
能完成至少一个电机的转动



### 开发历程
**电控组**
1. 环境搭建
- 9月27日：注册重庆大学学生邮箱并登录JetBrains申请教育许可证。
- 9月27日~9月29日：不断尝试下载STM32系列工具链，遭遇ST官网下载超时、登录账号页面加载不出、登进账号后404、点击下载后无反应。
- 9月30日：半夜在家用热点后终于成功，成功配置STM32系列工具链。
- 10月2日：学C语言时觉得VS COde的补全提示很阻碍思考，询问DeepSeek在settings.json里修改代码，最终关闭了补全提示而错误红线还保留着。
- 10月10日：硬件链接的绝望与战术止*：
  我们试图通过 ST-Link 将程序烧录进 STM32F103C8T6。但在 STM32CubeProgrammer 中，目标电压始终显示为 **0V**，并报错 `DEV_USB_COMM_ERR`。
  我们尝试了以下所有排查方法：
  1. 独立插 USB 给板子供电（红灯亮起，确认板子有电）。
  2. 对调 SWDIO 和 SWCLK 引脚（发现 ST-Link 指示灯进入闪烁状态，说明在尝试连接，但依然握手失败）。
  3. 更换了全新的 STM32 开发板，结果完全一样。
  4. 将 SWD 通信频率从 4000kHz 逐步降至 100kHz，并尝试了 Software reset 和 Hardware reset。
  5. 更换了不同 USB 数据线，确认设备管理器中存在 `STM32 STLink` 设备。
  最终我们判定：**克隆版 ST-Link 硬件本身的电压检测芯片已损坏。**


### 遇到的难点与解决方案
- **难点**：目标电压 0V，ST-Link 无法连接。
- **解决方案**：放弃依赖 ST-Link 烧录。直接使用 7.4V 电池连接 DRV8833 手动测试电机，用手动连线验证底层硬件是否完好。并购买新的ST-Link

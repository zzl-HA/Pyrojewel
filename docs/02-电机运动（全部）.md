## 电机运动（全部）

### 功能描述
使用 STM32F103C8T6 输出 PWM 波，通过 DRV8833 驱动模块控制 TT 马达的转动与调速。

#### 开发历程
**1. （下午）代码成功烧录**
经过连日排查，ST-Link 终于恢复连接。我们通过 CLion 成功将代码烧录进 STM32，底部日志显示 `Loaded 8256 bytes` 和 `System reset`，确认代码已成功装载进芯片！[烧录成功](烧录成功.png)

**2. 硬件接线与首次上电**
我们按照预设的引脚映射进行接线：
- STM32 `A0` -> DRV8833 `AIN1`
- STM32 `A1` -> DRV8833 `AIN2`
- STM32 `A4` -> DRV8833 `STBY`
- 电机接线 -> `AO1`、`AO2`
- 动力电池（7.4V） -> `VM`、`GND`
- **极其关键**：STM32 `GND` 与 DRV8833 `GND` 必须共地。

**3. 意外短路与安全排查**
首次接通动力电瞬间，接点处产生了火花，且电机未动作。
- 我们立刻采取紧急止损措施：
- 立刻拔掉电池。
- 用手触摸电池和驱动板，确认没有发烫，凑近闻也没有烧焦的糊味，排除了硬件损坏。
- 断开所有杜邦线，防止二次短路。

**4. 故障原因：新电池“虚电”导致的电流过小**
- 经过排查和学习，我们发现之前测试使用的是全新购买的 18650 平头电池。新电池出厂时通常只有微弱的“虚电”（电压不足以驱动大电流负载）。同时，平头电池在电池盒中存在接触不良的情况，需用手顶住才能勉强接触。
- 当我们用手按压住电池正极时，电机出现了转动的迹象；但一旦松手，接触断开，电机立即停止，且由于电流不稳定引发了火花。
- 我们将电池放入专用充电器进行充电，刚插入时指示灯为绿色（待机/未接触好），调整纸片垫紧接触后，指示灯转为红色（正在充电状态），进一步印证了电池处于极度亏电状态。

### ST-Link底层工具链排障与烧录攻坚

### 功能描述
解决 STM32 无法烧录代码的致命问题，将 CLion 编译好的程序成功写入 STM32F103C8T6 芯片，完成“从软件到硬件”的最后一步闭环。

#### 
- **10月10日全天 陷入绝境**：从白天到晚上，我们的 ST-Link 陷入了彻底瘫痪。报错经历了 `Target voltage 0V`、`USB communication error`、`could not connect (error 10061)` 等多个底层致命错误。我们尝试了更换新买的 ST-Link、降频至 480kHz、对调 SWDIO/SWCLK 引脚、重启电脑清理 USB 端口占用、甚至切换到 BOOT0 跳线模式，但依然无法成功写入。[烧录报错](烧录报错.png)
- **10月10日 20:00 转折点**：在万般无奈下，我们选择向有经验的学长求助。学长给出了最直接的建议：**“拔掉所有的线，重新插拔 ST-Link，重新接线，再试一次。”**[拔掉重插后](重插后.png)
- **10月10日 20:15 成功烧录**：我们严格按照建议执行，重插 ST-Link 并重新连接了杜邦线后，再次点击 CLion 的烧录按钮，进度条成功跑完，日志显示 `Download verified successfully`！代码成功注入了芯片！[烧录成功](烧录成功2.png)
- 但不知道原因电机又转不了了[无法转动的电机](无法转动的电机.png)
#### 为什么这样做（技术分析与反思）
为什么同样的硬件，重插一遍就能成功？这背后有极其真实的工程原因：
1. **克隆版工具的物理脆弱性**：廉价克隆版 ST-Link 的 USB 接口和杜邦线触点质量堪忧，多次插拔或长时间使用后，极易出现接触不良，导致底层数据握手失败。
2. **Windows USB服务的随机性**：Windows 底层的 USB 驱动服务在反复报错后，容易进入死锁状态，哪怕重启有时也无法彻底释放端口。
3. **外部经验的重要性**：我们在代码和配置上钻了牛角尖，学长的一句“重插重接”其实是在提醒我们：**一定不要忽视物理连接这一最基础、也最容易出问题的环节。** 硬件调试中，“接触可靠”永远是第一位的。
经过今天的事我们深刻认识到，遇到难题时，及时寻求外部技术支持，打破思维定式，也是一种极其重要的工程能力。

#### 遇到的难点与解决方案
- **难点**：底层 USB 通信错误（10061），无论怎么换配置、降频、重启电脑都无效。
- **解决方案**：停止软件层面的死磕，重新**物理接触**（换线、重插、重接），使用“物理手段”强行重置硬件状态。




#### 经验与反思
1. **动力电上电前，必须验证电源电压**：我们忽略了新电池需要充电的前提。在以后每次上电前，应当用万用表测一下电池盒输出端是否为 7.4V 左右，而不是盲目通电。
2. **弃用面包板走动力线**：面包板内部触点极小，无法承受电机启动瞬间的大电流，极易导致接触不良或火花。我们决定后续动力线全部采用杜邦线直接对接或焊接。
3. **接触可靠性是硬件的第一步**：平头电池与廉价弹簧电池盒的兼容性差。通过这次经历，我们知道在后续比赛中必须用纸片垫紧或购买凸头电池，确保车体在移动震动中永不断电。

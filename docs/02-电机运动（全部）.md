## 电机运动（全部）

### 功能描述
使用 STM32F103C8T6 输出 PWM 波，通过 DRV8833 驱动模块控制 TT 马达的转动与调速。


### 10月10日
#### 开发历程
**1. （下午）代码成功烧录**
经过连日排查，ST-Link 终于恢复连接。我们通过 CLion 成功将代码烧录进 STM32，底部日志显示 `Loaded 8256 bytes` 和 `System reset`，确认代码已成功装载进芯片。！[烧录成功](烧录成功.png)

**2. （傍晚）硬件接线与首次上电**
我们按照预设的引脚映射进行接线：
- STM32 `A0` -> DRV8833 `AIN1`
- STM32 `A1` -> DRV8833 `AIN2`
- STM32 `A4` -> DRV8833 `STBY`
- 电机接线 -> `AO1`、`AO2`
- 动力电池（7.4V） -> `VM`、`GND`
- **极其关键**：STM32 `GND` 与 DRV8833 `GND` 必须共地。

**3. 短路惊魂与安全排查**
首次接通动力电瞬间，接点处产生了火花，且电机未动作。我们立刻采取紧急止损措施：
- 立刻拔掉电池。
- 用手触摸电池和驱动板，确认没有发烫，凑近闻也没有烧焦的糊味，排除了硬件损坏。
- 断开所有杜邦线，防止二次短路。

**4. 故障真相：新电池“虚电”导致的电流瓶颈**
经过排查，我们发现之前测试使用的是全新购买的 18650 平头电池。新电池出厂时通常只有微弱的“虚电”（电压不足以驱动大电流负载）。同时，平头电池在电池盒中存在接触不良的情况（需用手顶住才能勉强接触）。
当我们用手按压住电池正极以改善接触时，电机出现了转动的迹象；但一旦松手，接触断开，电机立即停止，且由于电流不稳定引发了火花。
我们将电池放入专用充电器进行充电，刚插入时指示灯为绿色（待机/未接触好），调整纸片垫紧接触后，指示灯转为红色（正在充电状态），进一步印证了电池处于极度亏电状态。

**5.工具链彻底瘫痪与战术转移**
之前显示出3.12v，说明ST-Link的硬件电气连接是通的，但仍未连接成功。[3.12v图片](3.12v.png)
晚 17:00，我们更换了新的 ST-Link。在 STM32CubeProgrammer 中成功读取到了 3.30V 的目标电压，但报错 No STM32 target found。我们果断尝试在 CLion 中直接烧录（绕过官方软件），但底层报出 could not connect (error 10061)，Windows 系统拒绝了 ST-Link 的驱动服务。
**解决方法：重新使用旧的已烧录好的ST-Link**



#### 为什么这样做（经验与反思）
1. **动力电上电前，必须验证电源电压**：我们忽略了新电池需要充电的前提。在以后每次上电前，应当用万用表测一下电池盒输出端是否为 7.4V 左右，而不是盲目通电。
2. **坚决弃用面包板走动力线**：面包板内部触点极小，无法承受电机启动瞬间的大电流，极易导致接触不良或火花。我们决定后续动力线全部采用杜邦线直接对接或焊接。
3. **接触可靠性是硬件的第一步**：平头电池与廉价弹簧电池盒的兼容性极差。经此一役，我们在后续比赛中必须用纸片垫紧或购买凸头电池，确保车体在移动震动中永不断电。

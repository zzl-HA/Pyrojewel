## 舵机运动（单一）

### 功能描述
能完成至少一个舵机的转动


### 开发历程

#### 硬件清单 (Hardware)

- **控制板**: Arduino UNO (或其他兼容板)
- **舵机 1**: SG90 微型舵机 (蓝色塑料齿轮)
- **舵机 2**: MG995 金属齿轮舵机 (黑色)
- **供电模块**: 
    *   烧录代码时：USB Type-B 数据线 (连接电脑)
    *   独立运行时：电池盒
- **连接线**: 杜邦线若干

###  接线说明 

#### 1. 基础测试接线 (仅使用 SG90)
*   **棕色线 (GND)** -> Arduino `GND`
*   **红色线 (VCC)** -> Arduino `5V`
*   **橙色线 (Signal)** -> Arduino 数字引脚 `9`

**注意** ：如果同时驱动 MG995 金属舵机，**请勿**直接使用 Arduino 的 5V 引脚供电，以免电流过大烧毁开发板。必须使用外接电源，并将外接电源的地线 (GND) 与 Arduino 的 GND 共地。

#### 2. 脱离电脑独立供电
1. 先通过 USB 连接电脑，将代码烧录进 Arduino。
2. 拔下 USB 线。
3. 将线接入电池盒。
4. 板子通电后，舵机自动循环执行已烧录的程序。

### 代码片段

在 Arduino IDE 中上传以下代码，即可让舵机在 0°、90° 和 180° 之间来回摆动。

```cpp
#include <Servo.h>   // 引入舵机库

Servo myservo;       // 创建一个舵机对象

void setup() {
  myservo.attach(9); // 将舵机信号线绑定到 9 号引脚
}

void loop() {
  myservo.write(0);   // 转到 0 度
  delay(1000);        // 停顿 1 秒

  myservo.write(90);  // 转到 90 度 (正中间)
  delay(1000);

  myservo.write(180); // 转到 180 度
  delay(1000);
}
```

 #### 踩坑记录

1. 舵机接上不转？
   · 检查代码是否成功烧录。
   · 检查信号线（橙色）是否插在正确的数字引脚（如 9 号）。
   · 检查插头是否插紧。
2. 拔掉电脑就不转了？
   · Arduino 需要独立供电。需使用充电宝或电池盒通过 USB 接口或 DC 接口供电。
